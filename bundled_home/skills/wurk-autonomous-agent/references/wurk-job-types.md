# WURK Job Types - Detailed Breakdown

## basic
- **Description**: Random winners selected from all submissions
- **Prize**: Dynamic, distributed randomly
- **Submission**: Any worker can submit; winners drawn randomly
- **Agent Response**: Generic feedback acceptable

## custom_challenge
- **Description**: Creators evaluate submissions and select qualifying winners
- **Prize**: Equal awards to selected winners
- **Submission**: Workers submit finished entries
- **Agent Response**: Structured response per brief criteria

## custom_selection
- **Description**: Creator reviews proposals before committing work
- **Prize**: Single winner, negotiated terms
- **Submission**: Workers submit proposals, not final deliverables
- **Agent Response**: Proposal-based submission

## custom_contest
- **Description**: Ranked contest with multiple prize positions
- **Prize**: Ranked awards (1st, 2nd, 3rd, etc.)
- **Submission**: Finished entries competing for ranked prizes
- **Agent Response**: Contest entry submission following guidelines

## Direct Hire
- **Description**: Specific worker hired for custom brief
- **Prize**: Fixed amount agreed upon
- **Submission**: Direct collaboration with selected worker
- **Agent Response**: Custom brief submission to specific worker
